# 🏸 BADMAP 羽球管理

管理自己球隊的小網站,手機瀏覽器開網址就能用:

- 🏸 **打球場次** — 每場記出席(季打勾選 / 臨打報到)、場地費、用掉幾顆球,自動算出這場公款進出
- 👥 **球員名單** — 季打人員與臨打人員分開管理,季費繳納狀態一目了然,可看每個人出席幾場
- 💰 **公款收支** — 季費、臨打費、場地費自動記帳,買球和其他雜支手動記,隨時看得到餘額和羽球庫存
- 🏸 **羽球管理** — 登記球種(一筒幾顆、一筒多少錢),自動換算單顆成本,買球時選幾筒就自動算金額和顆數
- 📷 **球隊相簿** — 每週打完上傳照片,存在自己的 Google Drive,球友打開 App 都看得到
- 📱 **可以加到主畫面** — 手機瀏覽器選「加到主畫面 / 加入主畫面」後全螢幕開啟,沒網路也打得開(離線時顯示上次看到的資料)
- 🎨 **深淺色與主題色** — 預設跟隨系統,也可以在設定頁固定淺色 / 深色,主題色有綠 / 藍 / 橘 / 紫可選(只影響自己這支手機)

純靜態網頁,不需要伺服器,放在 GitHub Pages 上完全免費。架構參考 [FAMIAP](../260713%20Family%20APP)。

## 收費規則(可在「設定」頁調整)

| | 場地費 | 球費 | 每場付錢嗎 |
|---|---|---|---|
| **季打球員** | 已含在季費裡,由公款支付 | 公款買球 | ❌ 不用 |
| **臨打球友** | 每場收一次固定單場費(預設男 180 / 女 160) | 同上 | ✅ 當場收 |

- **臨打單場費依性別自動帶入**:球員資料上有男 / 女,加入場次時就帶對應金額;現場想個別調(只打一半、老朋友優待)直接改那一列的數字即可,不影響設定值。臨打報到列的 `男 / 女` 切換鈕加入一位後會維持不變,一群女生一起來不用每次重切。
- **羽球成本與庫存**:在「設定 → 羽球管理」登記球種(名稱 / 一筒幾顆 / 一筒多少錢),APP 自動換算成一顆多少錢。
  每一種球**各自算庫存**:買進顆數(收支頁的「買球」)− 用掉顆數(場次的用球明細)。
  記一場球時,登記過的球種會各列一行,用加減鈕點「這種用幾顆」——一場同時用兩種球(新球開場、練習球收尾)就分別記,
  各算各的錢、各扣各的庫存,旁邊即時顯示這種球還剩幾顆,剩不到 6 顆會標「快用完」。
- **季費**:一季收一次固定金額(例如 3000 元/季),只記「已繳 / 未繳」,不逐場扣款。
  **每個人可以收不一樣的錢**:季別設定的是「預設季費」,個別球員要調整就在他的球員資料裡填「個人季費」——
  學生半價填 1500、教練免繳填 0、留白就是跟大家一樣。收季費畫面會用每個人自己的金額,
  應收總額也是逐一加總算出來的;免繳的人不用按、直接算收齊。
- **每場公款進出** = 臨打收入 − 場地費。球費不列入每場現金流,因為買球那筆錢在買的時候就已經付掉了(重複算會變成記兩次帳);場次裡的「用球數」是拿來算**球材成本**和**庫存**用的。
- 每場結算會另外顯示「本場實際成本 ÷ 出席人數 = 每人成本」,方便檢查臨打單場費收得夠不夠。

## 部署到 GitHub Pages

程式碼已經在 <https://github.com/jie522/Badminton_APP>。剩下**開啟 Pages 這一步要自己在網頁上點**(只做一次):

1. 打開 <https://github.com/jie522/Badminton_APP/settings/pages>
2. Source 選 **Deploy from a branch**,Branch 選 `main` / `(root)`,按 **Save**
3. 等一兩分鐘,網址生效:**<https://jie522.github.io/Badminton_APP/>**
4. 手機打開網址 →「加入主畫面」,用起來就跟 App 一樣。把網址傳給球友就能共用

之後有改動:

```bash
git add -A && git commit -m "說明" && git push
```

> repo 是公開的,但**球員名單、收支、照片都不在 repo 裡**(存在你自己的 Google Sheet / Drive 和各自的手機),推上去的只有程式碼。

## Google Sheet 同步設定(一次性,約 5 分鐘,只有隊長要做)

沒設定也能用,只是資料只存在自己這支手機。設定完之後:資料存雲端、換手機不會不見、球友看得到同一份、可以上傳照片。

照 [apps-script/Code.gs](apps-script/Code.gs) 檔案開頭的 6 個步驟做:打開自己的 Google Sheet → 擴充功能 → Apps Script → 貼上程式 → 部署成網頁應用程式 → 把網址貼到 App 設定頁。

> ⚠️ **部署產生的 Apps Script 網址等於這份 Sheet 的鑰匙**:拿到網址的人就能讀寫你的球隊資料。
> 只私下傳給球友,**不要貼進這個公開 repo、Issue 或任何公開的地方**。
> App 把它存在每支手機自己的瀏覽器裡,不會進版控。

分頁(球員 / 季別 / 季費繳納 / 場次 / 羽球品項 / 帳目)App 會自動建立,裡面除了程式用的 id 欄位,也有「季打名單」「臨打名單」這種給人看的中文欄位,直接在 Sheet 上就能對帳。

**球友的手機**:貼同一個網址,啟用時「要不要上傳現有資料」選**取消**,就會直接讀到隊長那份資料。

## 資料存哪裡?

| 資料 | 沒啟用同步 | 啟用同步後 |
|---|---|---|
| 球員 / 季別 / 季費 / 場次 / 羽球品項 / 帳目 | 手機瀏覽器 localStorage | Google Sheet(手機保留一份快取,離線也看得到) |
| 照片 | 無法上傳 | Google Drive 的「羽球管理APP 相簿」,依月份分子資料夾 |
| 收費金額、Apps Script 網址 | 每支手機各自設定 | 同左(裝置設定不同步) |

沒啟用同步時,可以用「設定 → 資料備份」匯出 JSON 檔換手機。

## 常見狀況

- **照片傳不上去**:確認設定頁的同步已啟用;公司或學校的 Google 帳號可能禁止「知道連結的人可檢視」,照片會存進 Drive 但別人看不到,換個人帳號部署即可。
- **改了程式碼但手機沒更新**:`index.html` 裡 `css/style.css?v=` 和 `js/*.js?v=` 的版本參數改成當天日期,`sw.js` 的 `CACHE` 版本也要一起換,再 push,否則手機會用快取的舊檔。
- **兩個人同時改同一場**:整張表覆寫的設計是「後存的蓋前面的」,同一時間編輯同一筆資料時以最後儲存的為準。
